# Fluent navigation icons

These SVGs come from Microsoft's [Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons) repository. They are bundled in Dictate under the repository's MIT license, included here as `LICENSE`.

The filenames are shortened for Dictate's navigation mapping; the source glyphs remain unmodified and are tinted at runtime for the selected light or dark appearance.
